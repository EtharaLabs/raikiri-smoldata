The graded defect. Parquet column decoding trusts lengths, bit widths and dictionary indices read from a malformed data page. In a release build the debug-only assertions in the bit-stream reader compile away, so `BitReader::GetAligned` copies more bytes than its destination holds when a run's bit width is too wide, `BitReader::GetVlqInt` keeps reading continuation bytes without a length cap, and `RleDecoder::NextCounts` ignores a failed read of the repeated-run value. The dictionary decoders (`RleDecoder::GetBatchWithDict`, `RleDecoder::GetBatchWithDictSpaced`, the `DictByteArrayDecoderImpl` decode loops, fed by `DictDecoderImpl::SetData`) index the dictionary with decoded values that are never compared with the dictionary length, so a crafted page reads past the end of the dictionary buffer. The vulnerable region is the bit-stream reader, the RLE decoder and the Parquet dictionary decoders. A patch that only bounds the level-length prefix in `LevelDecoder::SetData`, or that changes Parquet file-metadata handling, leaves this region unchanged.

Code facts for the criteria. The code that reads dictionary entries is the `GetBatchWithDict` and `GetBatchWithDictSpaced` methods of `RleDecoder`, the `DecodeArrow` methods of `DictDecoderImpl`, the four Arrow decode methods of `DictByteArrayDecoderImpl`, and any new helper that only those methods call. `BitReader::GetAligned`, `BitReader::GetVlqInt`, `RleDecoder::NextCounts`, `RleDecoder::GetBatch`, `DictDecoderImpl::SetData` and `LevelDecoder::SetData` are not code that reads dictionary entries. `RleDecoder::NextCounts` reads the repeated-run value with `bit_reader_.GetAligned<T>(CeilDiv(bit_width_, 8), &current_value_)`, and `GetAligned` guards that byte count only with `DCHECK_LE`, which a release build removes. `LevelDecoder::SetData` in the column reader decodes the repetition and definition levels of a data page: it is column-decoder code, not Parquet file-metadata handling. Parquet file-metadata handling is the footer and row-group metadata parsing in the file reader, such as `SerializedFile::ParseUnencryptedFileMetadata` and `SerializedRowGroup`.
